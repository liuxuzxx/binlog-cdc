# v1.0.0

首次以 `liuxuzxx/binlog-cdc` 发布。

- 提供 MySQL Binlog → Kafka 实时同步，以及仓库中已接通的其他 Source → Sink 链路。
- 提供 `flink-cdc-init` 的 MySQL 全量初始化程序。
- 统一两个 Rust crate 和 `/version` 接口的版本号为 `1.0.0`。
- 提供 218 上的一键发布脚本：推送 `liuxuzxx/flink-cdc-rs:v1.0.0-<10 位提交号>`；GitHub Actions 自动构建并上传 Linux x86_64 二进制和校验文件。

使用方法、支持范围和生产观测数据见 [README](../../README.md)。
